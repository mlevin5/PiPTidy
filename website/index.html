Picture-in-Picture is useful.

Picture-in-Picture parked over the exact thing you need to see is not.

001

Not just four corners.

PiP Tidy searches a full scoring map for an exact position and size. If the screen is crowded, it can shrink the video instead of bulldozing through important content.

002

Foreground windows count.

A smaller window in front probably matters. PiP Tidy gives it extra protection while looking for somewhere less annoying to land.

003

Live from launch.

Open PiP Tidy and it starts looking. A PiP that is already open is detected automatically, and Live Placement keeps reconsidering as your workspace changes.

[ approximately how the magic happens ]

Three steps. No browser extension.

  1. 1

    Find the PiP

    PiP Tidy detects the browser’s native Picture-in-Picture window.

  2. 2

    Read the room

    A low-resolution importance map identifies busy content and foreground windows.

  3. 3

    Make room

    The largest placement that clears the safety checks wins.

[ no cloud // no llm // no generative ai ]

Your screen stays on your Mac.

Screen images are reduced to a temporary, low-resolution importance map in memory. Placement uses local image statistics and window geometry—not an LLM or cloud vision service. PiP Tidy does not save or transmit screenshots. The beta has no analytics, accounts, ads, or cloud processing.
